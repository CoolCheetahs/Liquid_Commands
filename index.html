$ python ~/storage/downloads/liquid_all.py --setup
2. Every timeStarts the server and opens your browser.
$ liquid

localhost:8080
4. Put it online: GitHub Pages (one time setup)Free, no branding. Files to upload: index.html (this page), manifest.json, sw.js and your own icon picture named exactly icon.png (a square PNG, ideally 512x512 or bigger).

A. Get the files ready
1. Save this page and name it exactly index.html (all lowercase, no dot at the start).
2. Keep manifest.json, sw.js and your icon.png in the same folder. Rename your picture to exactly icon.png first (all lowercase). The app finds its icon by this name, so a different name will not show.

B. Make a GitHub account
1. In your browser go to github.com and tap Sign up.
2. Enter your email, a password and a username. Remember the username, it becomes part of your link.
3. Solve the puzzle, then enter the code GitHub emails you.
4. Skip any personalization questions.

C. Make the repository (the folder that holds your files)
1. Tap + (top right, or inside the menu) then New repository.
2. Repository name: liquid (any short name, no spaces).
3. Choose Public. Leave everything else alone.
4. Tap Create repository.

D. Upload the files
1. On the new empty repository page, tap uploading an existing file. (Or tap Add file, then Upload files.)
2. Tap choose your files and select all the files. Wait until they are all listed.
3. Scroll down and tap Commit changes.

E. Turn on the website
1. Open the Settings tab of the repository, then Pages in the side menu.
2. Under Build and deployment, set Source to Deploy from a branch.
3. Set Branch to main and the folder to / (root), then tap Save.
4. Wait 1 to 2 minutes, then refresh. The page shows: Your site is live at yourname.github.io/liquid.

F. Install the app
1. Open that link in your browser (not the GitHub app).
2. Tap the ⋮ menu, then Install app (or Add to Home screen). Confirm.
3. Open it from the new home screen icon.

If something goes wrong
Page not found: wait a couple more minutes, and check that the file is named exactly index.html in the repository.
No Install app option: check that manifest.json, sw.js and icon.png are all in the repository and the link starts with https://.
5. Update the page itself laterOpen your repository, tap Add file, then Upload files and upload the new index.html. It replaces the old one. Wait 1 to 2 minutes and reopen the app.
6. Change the home screen icon (GitHub)The Upload picture button below only changes this page inside your browser. It does not change the installed app icon. The home screen icon is the picture file stored in your GitHub repository, so to change it you replace that file there and install the app again.

Important: the file name matters
The app finds its icon by the name written in manifest.json. That name is icon.png. Your new picture must be a square PNG named exactly icon.png (all lowercase), or it will not show. If you upload a picture with the same name, it replaces the old one.

A. Replace the icon picture on GitHub
1. Open github.com in your browser and sign in.
2. Open your repository (liquid).
3. Get your new picture ready and rename it to exactly icon.png.
4. Tap Add file, then Upload files.
5. Choose your icon.png. It replaces the old one because the name is the same.
6. Scroll down and tap Commit changes.
7. Wait 1 to 2 minutes for GitHub Pages to update.

B. Reinstall the app so the new icon shows
1. On your home screen, press and hold the old app, then tap Uninstall (or Remove).
2. Open your browser, go to Settings, then Privacy and security, then Clear browsing data, and clear cached images and files. This makes sure your browser does not reuse the old icon.
3. Open your link (yourname.github.io/liquid) in your browser.
4. Tap the ⋮ menu, then Install app (or Add to Home screen). Confirm.
5. The new icon now shows on your home screen.

Want to keep a different file name?
You can, but then manifest.json must say the same name.
1. In your repository, tap manifest.json, then the pencil (edit) button.
2. Find the two places that say icon.png and change both to your exact file name, including the ending (for example myphoto.jpg). If it is a JPG, also change image/png to image/jpeg in both places.
3. In index.html, the two small links near the top also say icon.png. Change them the same way, or ignore them, because they only affect the browser tab icon.
4. Tap Commit changes, upload your picture with that exact name, then reinstall the app as in B.

If the old icon still shows
Wait a few more minutes and try again. Check that the picture was committed in the repository and that its name matches the name in manifest.json exactly. Clear your browser's cached images and files again, then reinstall.
